次のAndroidセキュリティ情報を日本語で要約してください: {url}

必ず以下の見出し構造（Markdown）で出力してください。

# 全体像
- 総件数と、深刻度別の件数（Critical: N件 / High: N件）
- コンポーネント別の件数内訳

# 重要な脆弱性
- Critical および攻撃の兆候があるものを個別に列挙
- 各項目は「CVE番号（コンポーネント / 深刻度）: 内容」の形式
- Critical は省略せず全件記載

# 傾向
- 件数が多いコンポーネント領域を上位順に、件数付きで

制約:
- 必要な場合はマーメイド図で補足すること
- High全件の羅列は不要（Criticalと攻撃兆候ありは必ず全件）
- CVE番号・深刻度は改変しないこと
- 詳細な情報がurlリンクとして残されている場合は、詳細として残すこと
